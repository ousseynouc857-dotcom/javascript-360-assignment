# Array Cardio Day 1

This project is a set of JavaScript exercises using arrays of people and
inventors.

## How it works

The finished page uses array methods to filter, sort, map, and count data.
Open the browser's developer console to see the results.

Open `index-finished.html` for the completed exercises. `index-start.html` is
the starter version.

## What I learned

- How to use `filter`, `map`, `sort`, and `reduce`.
- How to work with arrays of objects.
- How to display results in the developer console.
