# javascript-360-assignment

A collection of projects based on Wes Bos JavaScript course videos.

## Drum Kit

A browser drum kit that plays a drum sound when you press its matching key
(A, S, D, F, G, H, J, K, or L).

## How it works

Each key and audio element has a matching `data-key` value. JavaScript listens
for keyboard presses, finds the matching audio and key elements, and plays the
sound. CSS adds a brief animation to show which key was pressed.

## What I learned

- How to respond to keyboard events with JavaScript.
- How to select and update HTML elements using the DOM.
- How HTML audio elements play sound and CSS transitions add visual feedback.
