# Drum Kit

A browser drum kit that plays a sound when you click a drum or press its
matching key (A, S, D, F, G, H, or J).

## How it works

JavaScript listens for keyboard presses and clicks, then plays the matching
sound using the Web Audio API. CSS styles the drum buttons and shows which one
is playing.

## What I learned

- How HTML, CSS, and JavaScript work together.
- How to handle keyboard and click events.
- How to select and update elements in the DOM.
- How to create sounds with the Web Audio API.
