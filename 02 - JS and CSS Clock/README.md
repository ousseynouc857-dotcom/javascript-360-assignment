# JavaScript and CSS Clock

This project shows an animated clock in the browser. The HTML, CSS, and
JavaScript are all in `index.html`.

## How it works

JavaScript reads the current time and rotates the clock hands. It updates
every second, and CSS makes the movement smooth.

## What I learned

- How to get the time with JavaScript.
- How to select HTML elements and change their styles.
- How CSS transforms and transitions work.
- How to run code repeatedly with `setInterval`.
