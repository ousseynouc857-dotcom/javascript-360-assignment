# JavaScript and CSS Clock

A browser clock that displays the current time using animated hour, minute,
and second hands. The HTML, CSS, and JavaScript are together in `index.html`.

## How it works

JavaScript gets the current time with `Date`, converts it into angles, and
rotates each hand using CSS transforms `setInterval` updates the clock every
second while CSS transitions make the hands move smoothly.

## What I learned

How to read the current time and work with seconds, minutes, and hours.
 How to select HTML elements and change their styles with JavaScript
 How CSS transforms and transitions can animate elements.
 How `setInterval` runs an update repeatedly
