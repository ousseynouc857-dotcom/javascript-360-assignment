# CSS Variables

This project lets you change an image's spacing, blur, and color.

## How it works

The finished page uses range and color controls. JavaScript reads their values
and updates CSS variables, which change the image's style.

Open `index-end.html` to try it. `index-start.html` is the starter version.

## What I learned

- How to create and use CSS variables.
- How to read input values with JavaScript.
- How JavaScript can update CSS styles.
