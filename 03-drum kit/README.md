# JavaScript Drum Kit

This project plays drum sounds when you press the matching keyboard keys.
The page uses `index.html` and `style.css`.

## How it works

JavaScript matches a pressed key to an audio element and highlights its key.
The sound files are expected in a `sounds` folder.

## What I learned

- How to listen for keyboard events.
- How to find and update HTML elements with JavaScript.
- How CSS can show which key is playing.
- How to play audio in a web page.
