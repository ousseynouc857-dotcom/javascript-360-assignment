# Flex Panel Gallery

This project displays five photo panels that open when clicked.

## How it works

The finished page uses CSS Flexbox to arrange the panels. JavaScript adds and
removes CSS classes when a panel is clicked, and CSS animates the change.

Open `index-finished .html` to try the working version. `index-start.html` is
the starter version.

## What I learned

- How to arrange content with CSS Flexbox.
- How to respond to clicks with JavaScript.
- How to animate changes with CSS transitions.
